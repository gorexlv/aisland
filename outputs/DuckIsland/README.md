# Duck Island · 会议版

适用于 Apple Silicon、macOS 15 及以上。双击上一级的 `Duck Island.app` 运行。

## 操作

1. 点击顶部刘海左侧黄鸭，下方从左向右垂下三个动物挂件：单手悬挂的猴子（会议）、抱绳树袋熊（读屏）、斜挂鹦鹉（批阅）；悬停显示名称，挂件轻微摆动，遵循系统减少动态效果设置。树袋熊用于框选读屏，鹦鹉用于截图批阅。
2. 点击「会议」，按系统提示授权麦克风、语音识别、屏幕与系统音频录制。首次拒绝后，应用会提供打开系统设置的入口；系统要求重新启动时，请重开应用。
3. 同时采集系统输出和默认麦克风，进行中文实时转写。系统声音直接采集，不依靠麦克风收外放，因此支持耳机或 Mac 扬声器输出。会采集其他应用同时播放的声音，请停止不需要记录的播放。
4. 再次点击黄鸭结束会议。应用等待尾部识别结果，再调用本机 Codex CLI 生成摘要、关键结论、可执行 tickets 和待确认事项，与完整原文一并写入 Apple 备忘录默认账户的默认文件夹中新建的日期时间记录。首次写入时，macOS 可能要求允许 Duck Island 控制备忘录。
5. 如备忘录权限被拒绝，文字保留在面板和本地文件，可授权后点「写入备忘录」重试，也可以直接复制。成功后界面显示备忘录实际名称及文件夹，点击名称可打开该记录。

右侧显示音量动画与估算句数，点击可收起或展开文字。菜单栏黄鸭可显示、复位和退出。正常退出正在进行的会议时，会先停止、整理和保存。

## 文字和音频

- 系统音频和麦克风同时采集，分别切成短片段，由单个活动识别任务依次处理，按时间排列，分别标为「会议声音」「我的麦克风」。这些是音频来源标签，不是发言人身份识别。
- 外放声音也可能被麦克风再次拾取，因此有产生重复文字的可能；耳机通常可以减少这一问题。
- 使用 Apple 中文语音识别，优先本机处理；本机不支持时使用 Apple 在线识别。
- 当前版本实时消费音频，不保存原始音频或屏幕画面。
- 文字备份位于 `~/Library/Application Support/DuckIsland/Meetings/`，面板中「本地文字备份」可定位文件。转写时定期备份，停止后再次保存。
- 长会议自动分段识别。识别或采集故障会结束会议并保存已经获得的文字；录音与转写仍受系统权限、设备状态及 Apple 服务可用性影响。

## Codex 总结

- 使用已安装的 Codex CLI 和现有登录凭据，在后台非交互运行。转写文字会发送给 Codex 服务进行分析。
- 调用使用独立临时目录、只读沙盒、临时会话，不载入用户自定义配置；禁用 shell、应用、插件、多智能体、浏览器及 hooks，只要求返回结构化分析，不执行 tickets。
- 每条 ticket 包含任务、负责人、截止时间、验收标准、原文依据。未明确的信息标为待确认。
- 超过三分钟、登录过期或分析失败时，先将原文和失败说明写入备忘录，并显示「重试总结」。重试成功会按返回的 note ID 更新同一条备忘录，避免重复创建。
- 界面展示 Notes 实际返回的名称与文件夹。记录原文、分析结果都包含在本地文字备份中。
- 已使用虚构测试会议实际调用 Codex CLI，验证生成摘要和两条可执行 tickets；新建/更新 Notes 脚本均通过编译检查。未用真实会议内容进行测试。

## 授权循环修复

已确认旧临时签名在每次更新后改变 cdhash，系统日志显示旧授权签名与当前版本不匹配。构建改为使用专用本地钥匙串中的固定代码签名证书（仅代码签名用途），保存在 `~/Library/Application Support/DuckIsland/Signing/`。请保留该目录，后续更新复用同一证书。

同时取消 CoreGraphics 前置授权阻断，以 ScreenCaptureKit 实际请求为准。本次迁移已清理本应用失效的屏幕录制授权，因此需要对新签名重新授权一次。未更改其他应用的录制权限。

回归验证：修改应用资源后 CDHash 改变，但证书绑定的 designated requirement 保持一致；更新包通过原身份要求验证。

## 双路识别修复

在这台 Mac 上，同一语言的两个并行 SFSpeechRecognizer 任务会互相打断，产生 No speech detected。固定中文语音测试已复现：单路正常，双路旧实现反复失败。现已改为短片段排队识别，保留同时采集与来源标签。

双路回归测试结果：两路各输入 262 个音频缓冲，共 8 个片段，两路均生成文字，识别错误为空。真实系统声音采集到转写也已通过固定测试语音验证。停止后会等待排队片段完成，并显示剩余数量。

面板显示系统声音与麦克风各自的输入状态；无文字时区分未接入、静音和识别失败。每次结束保存不含原始音频的 diagnostics.txt，便于定位来源和识别错误。

已取消排除应用自身声音的过滤，系统声音按全部来源采集。语音测试入口：`--test-speech <音频路径> --dual`（需要通过 LaunchServices 启动以使用本应用已授予的语音识别权限）。

## 后台保存与工作区

停止会议后自动收起面板，尾部转写异步收尾；为避免 Apple 识别任务互相打断，尾部收尾期间暂不启动下一段录音。Codex 分析、备份和 Notes 写入均在后台执行，此时可开始下一场会议。每个任务使用独立会议快照，避免结果串入新的会议。

Notes 写入在同签名程序的独立辅助进程中执行，不阻塞界面，也不主动展示 Notes。成功后在灵动岛下方显示一行包含实际备忘录名称的通知，3 秒后消失，应用继续运行。分析失败仍保存原文；写入失败保留本地记录并提示。正常退出会等待后台任务结束。

窗口加入所有工作区，使用 stationary 行为及无窗口动画设置；工作区切换后恢复窗口前置，不激活应用。

新增后台流程测试覆盖：会议快照内容、先备份后导出、分析失败后的原文保存、导出失败保留备份；不创建测试备忘录。

## 树袋熊 · 框选读屏

点击树袋熊，选择当前桌面上的窗口；只有一个窗口时直接进入。窗口上显示静态画面，拖动框选需要提取的区域，松开后在本机识别中英文文字并自动保存。Esc 或面板“取消”可退出框选。未识别到文字时提示重新框选，不创建空白记录。

识别结果显示在灵动岛下方，可复制、查看保存文件、重新框选或切换窗口。识别失败、窗口关闭和保存失败会给出提示；保存失败仍保留文字并提供“重试保存”。每次重新框选都会获取窗口最新截图。

记录保存在 `~/Library/Application Support/DuckIsland/ScreenReads/日期时间-编号/`，包括 `文字.txt`、仅包含框选区域的 `region.png`、窗口来源及范围 `source.json`。完整窗口截图仅用于临时框选，不保存到读屏记录中。

使用 Apple Vision 本机文字识别，不调用 Codex，不上传框选画面。旧的聊天、语音对话、browser use/computer use 和本地 MCP 控制桥接已移除。批阅的语音意见提取为独立 VoiceInput，会议的 Codex 总结功能保持原样。

验证：混合中英文识别、框外内容排除、裁剪坐标方向、本地文件写入、无文字和无效区域处理，均通过自动测试。Apple 文档：https://developer.apple.com/documentation/vision/recognizing-text-in-images

## 鹦鹉 · 批阅

1. 点击鹦鹉扫描当前桌面。多个窗口显示黄色高亮边框及选择列表，可点击窗口或列表选择；只有一个窗口时直接选中。
2. 窗口旁显示独立批阅侧边栏。窗口移动时侧边栏跟随；右侧空间不足时移到左侧，屏幕空间不足时贴在屏幕内侧。切换到没有目标窗口的工作区会隐藏批阅面板。
3. 点击“暂停”截取目标窗口，用静态截图覆盖原窗口。拖动框选区域；重复拖动可添加多个区域，支持重叠。框选区域以编号标记。
4. 点击已有框选区域可开始语音评审；侧边栏也可选择区域后点击麦克风。语音实时填写到意见编辑框，支持手动修订。批阅期间不能同时启动会议或读屏，以避免语音识别冲突。
5. “恢复”会先完成语音收尾、保存截图和批阅，移除截图遮罩，让原应用继续接收操作。再次暂停会获得新截图，旧记录继续保留在侧边栏。
6. 侧边栏展示区域缩略图和意见，可随时编辑已有意见。“完成并复制”把所有区域图片和意见按编号放入系统剪贴板，移除遮罩；可粘贴到支持图文的应用。关闭按钮保存本地记录并退出批阅。

剪贴板同时提供 RTFD（独立图片附件+意见）、HTML、纯文字及整张图文图片。不同目标应用支持的格式不同，纯文本输入框只会粘贴文字。完成时会替换系统剪贴板原有内容。

本地批阅保存在 `~/Library/Application Support/DuckIsland/Reviews/日期时间-编号/`，包含每次暂停的原始截图、带框选编号的截图、区域坐标与意见 JSON、文字汇总。侧边栏“查看本地批阅”可定位。语音不保存原始音频，批阅不调用 Codex，也不上传截图或意见。

验证：原生构建及签名通过；测试覆盖正反向框选、越界裁剪、小区域过滤、多显示器坐标换算、截图裁剪方向、图片与意见的 RTFD 序列化，以及独立测试剪贴板中的多图片/意见还原。实际界面已验证鹦鹉入口及窗口侧边栏。测试剪贴板独立于系统通用剪贴板，不覆盖用户当前剪贴板。


### 批阅按暂停画面组织

一次暂停对应一张完整截图。框选仅在这张图上追加编号标记；侧边栏每张图显示一次，下方列出该图各标记的意见。新保存文件夹每次暂停只输出一张完整标记 PNG，意见与坐标另存为文本和 JSON。完成复制时，RTFD、HTML 和纯文字均按画面分组；不再把各框选区域裁切成独立图片。无框选的暂停画面也保留并可复制。

回归测试覆盖：同一画面两个标记只生成一个图片附件；两次暂停生成两个完整尺寸附件；HTML 图片数量及各图对应意见顺序正确。
