# Duck Island · 会议版

适用于 Apple Silicon、macOS 15 及以上。双击上一级的 `Duck Island.app` 运行。

## 操作

1. 点击顶部刘海左侧黄鸭，下方只垂下一个单手悬挂的猴子挂件（会议）；悬停显示名称，挂件轻微摆动，遵循系统减少动态效果设置。读屏与批阅不再有挂件，统一从 `Option + Shift + Enter` 的 Mo 启动框进入，也可用菜单栏“唤起 Mo ⌥⇧ Enter”。
2. 点击「会议」，按系统提示授权麦克风、语音识别、屏幕与系统音频录制。首次拒绝后，应用会提供打开系统设置的入口；系统要求重新启动时，请重开应用。
3. 同时采集系统输出和默认麦克风，进行中文实时转写。系统声音直接采集，不依靠麦克风收外放，因此支持耳机或 Mac 扬声器输出。会采集其他应用同时播放的声音，请停止不需要记录的播放。
4. 再次点击黄鸭结束会议。应用等待尾部识别结果，再调用本机 Codex CLI 生成摘要、关键结论、可执行 tickets 和待确认事项，与完整原文一并写入 Apple 备忘录默认账户的默认文件夹中新建的日期时间记录。首次写入时，macOS 可能要求允许 Duck Island 控制备忘录。
5. 如备忘录权限被拒绝，文字保留在面板和本地文件，可授权后点「写入备忘录」重试，也可以直接复制。成功后界面显示备忘录实际名称及文件夹，点击名称可打开该记录。

右侧显示音量动画与估算句数，点击可收起或展开文字。菜单栏黄鸭可显示、复位和退出。正常退出正在进行的会议时，会先停止、整理和保存。

## 文字和音频

- 系统音频和麦克风同时采集，分别切成短片段，由单个活动识别任务依次处理，按时间排列，分别标为「会议声音」「我的麦克风」。这些是音频来源标签，不是发言人身份识别。
- 外放声音也可能被麦克风再次拾取，因此有产生重复文字的可能；耳机通常可以减少这一问题。
- 使用 Apple 中文语音识别，优先本机处理；本机不支持时使用 Apple 在线识别。
- 当前版本实时消费音频，不保存原始音频或屏幕画面。
- 文字备份位于 `~/Library/Application Support/DuckIsland/Meetings/`，面板中「本地文字备份」可定位文件。转写时定期备份，停止后再次保存。
- 长会议自动分段识别。识别或采集故障会结束会议并保存已经获得的文字；录音与转写仍受系统权限、设备状态及 Apple 服务可用性影响。

## Codex 总结

- 使用已安装的 Codex CLI 和现有登录凭据，在后台非交互运行。转写文字会发送给 Codex 服务进行分析。
- 调用使用独立临时目录、只读沙盒、临时会话，不载入用户自定义配置；禁用 shell、应用、插件、多智能体、浏览器及 hooks，只要求返回结构化分析，不执行 tickets。
- 每条 ticket 包含任务、负责人、截止时间、验收标准、原文依据。未明确的信息标为待确认。
- 超过三分钟、登录过期或分析失败时，先将原文和失败说明写入备忘录，并显示「重试总结」。重试成功会按返回的 note ID 更新同一条备忘录，避免重复创建。
- 界面展示 Notes 实际返回的名称与文件夹。记录原文、分析结果都包含在本地文字备份中。
- 已使用虚构测试会议实际调用 Codex CLI，验证生成摘要和两条可执行 tickets；新建/更新 Notes 脚本均通过编译检查。未用真实会议内容进行测试。

## 授权循环修复

已确认旧临时签名在每次更新后改变 cdhash，系统日志显示旧授权签名与当前版本不匹配。构建改为使用专用本地钥匙串中的固定代码签名证书（仅代码签名用途），保存在 `~/Library/Application Support/DuckIsland/Signing/`。请保留该目录，后续更新复用同一证书。

同时取消 CoreGraphics 前置授权阻断，以 ScreenCaptureKit 实际请求为准。本次迁移已清理本应用失效的屏幕录制授权，因此需要对新签名重新授权一次。未更改其他应用的录制权限。

回归验证：修改应用资源后 CDHash 改变，但证书绑定的 designated requirement 保持一致；更新包通过原身份要求验证。

## 双路识别修复

在这台 Mac 上，同一语言的两个并行 SFSpeechRecognizer 任务会互相打断，产生 No speech detected。固定中文语音测试已复现：单路正常，双路旧实现反复失败。现已改为短片段排队识别，保留同时采集与来源标签。

双路回归测试结果：两路各输入 262 个音频缓冲，共 8 个片段，两路均生成文字，识别错误为空。真实系统声音采集到转写也已通过固定测试语音验证。停止后会等待排队片段完成，并显示剩余数量。

面板显示系统声音与麦克风各自的输入状态；无文字时区分未接入、静音和识别失败。每次结束保存不含原始音频的 diagnostics.txt，便于定位来源和识别错误。

已取消排除应用自身声音的过滤，系统声音按全部来源采集。语音测试入口：`--test-speech <音频路径> --dual`（需要通过 LaunchServices 启动以使用本应用已授予的语音识别权限）。

## 后台保存与工作区

停止会议后自动收起面板，尾部转写异步收尾；为避免 Apple 识别任务互相打断，尾部收尾期间暂不启动下一段录音。Codex 分析、备份和 Notes 写入均在后台执行，此时可开始下一场会议。每个任务使用独立会议快照，避免结果串入新的会议。

Notes 写入在同签名程序的独立辅助进程中执行，不阻塞界面，也不主动展示 Notes。成功后在灵动岛下方显示一行包含实际备忘录名称的通知，3 秒后消失，应用继续运行。分析失败仍保存原文；写入失败保留本地记录并提示。正常退出会等待后台任务结束。

窗口加入所有工作区，使用 stationary 行为及无窗口动画设置；工作区切换后恢复窗口前置，不激活应用。

新增后台流程测试覆盖：会议快照内容、先备份后导出、分析失败后的原文保存、导出失败保留备份；不创建测试备忘录。

## Mo 启动框 · 附着读屏

按 `Option + Shift + Enter` 唤起启动框。第一步选窗口：当前最前窗口排第一并标记“当前”，支持搜索应用名与窗口标题，↑ / ↓ 切换、Enter 确认。第二步选能力：批注（推荐，截图进入批阅）或 OCR 读屏。选择会成为输入框内的标签，可再输入一句“意图”备注（可选），Enter 开始。Mo 附着到所选窗口并立即开始：批注自动截图进入批阅；OCR 显示框选画面。同一时间只附着一个窗口，`Option + E` 结束当前工作。

附着 OCR：点击 Mo 球或按 `Option + Enter` 重新框选（每次获取窗口最新截图）。左侧按钮列出本次工作的 OCR 记录，点开可查看并编辑识别文字；右侧音频按钮用最新识别文字开始 Mo 实时对话，默认关闭。识别结果可复制、查看保存文件。未识别到文字时提示重新框选，不创建空白记录；保存失败保留文字并提供“重试保存”。

记录保存在 `~/Library/Application Support/DuckIsland/ScreenReads/日期时间-编号/`，包括 `文字.txt`、仅包含框选区域的 `region.png`、窗口来源、范围及意图的 `source.json`。完整窗口截图仅用于临时框选，不保存到读屏记录中。

使用 Apple Vision 本机文字识别，不调用 Codex，不上传框选画面。旧的聊天、语音对话、browser use/computer use 和本地 MCP 控制桥接已移除。批阅的语音意见提取为独立 VoiceInput，会议的 Codex 总结功能保持原样。

验证：混合中英文识别、框外内容排除、裁剪坐标方向、本地文件写入、无文字和无效区域处理，均通过自动测试。Apple 文档：https://developer.apple.com/documentation/vision/recognizing-text-in-images

## 批注 · 呼吸灯批阅

1. 在启动框选择窗口与“批注”后，右上方出现可拖动的呼吸灯，始终限制在目标窗口内。点击灯或按 `Option + Enter`进入／退出审阅。
2. 审阅时窗口边缘亮起青绿色光晕，灯下出现最大约 350×240 点的小截图预览。预览始终在灯下方，横向靠近目标窗口左缘或右缘。目标窗口显示当前截图并接收框选，退出批阅后恢复原应用操作。
3. 在目标应用窗口内框选会新增意见并自动开始语音录入；选框与编号会在原窗口持续保留，录音时显示红色状态点，开始或停止录音不会退出审阅。只有删除对应意见才移除该框。小预览仅用于查看与切换意见，不接收框选。编号圆点直接横排悬浮在截图底部，不显示 Header、Footer 或转写正文。正在录音的意见带红色录音角标。
4. 点击另一个编号切换意见；同一截图内先收尾原录音，再继续录入新意见。呼吸灯右下按钮切换 Audio／Text 输入模式，录音中切换会先收尾并保留转写。转写失败或权限未授予时，可右键灯打开“编辑意见与记录”查看状态并手动输入。
5. 灯上方只显示一个历史截图数量按钮。点击后打开独立的普通历史窗口，并释放原应用的框选遮罩；原应用可继续点击操作。顶部横向切换截图，下方左侧尽量放大显示完整截图和框选标记，点击框选切换对应意见；右侧查看带真实录音时间戳的转写片段并编辑意见，左右区域可拖动调整宽度，修改自动保存；关闭前再次保存，保存失败时保留历史窗口和修改。录音准备、录音和收尾期间不允许打开历史，弹窗打开时禁用批阅切换和录音。右键“截取新画面”可增加一张截图。
6. 灯左下方历史/完成入口先收尾语音并保存全部记录，然后关闭预览、熄灭光晕，打开历史页；底部“保存并关闭”旁提供 Apple Notes（文字与编号截图附件）、复制图文、发送到 Codex。直接分发版的 Codex 入口在终端创建新的 Codex CLI 交互会话，附上截图，并从同目录 comments.txt 读取完整意见；不会复用或覆盖已有对话。需要本机已安装并登录 Codex CLI。
7. 所有后续操作失败时保留本地批阅，可以再次处理。Notes 写入需要自动化授权；App Store 版不启动外部 Codex CLI。只有主动点击相应处理动作才会写入 Notes、覆盖剪贴板或打开 Codex。

窗口移动时呼吸灯跟随并保留相对位置，预览重新计算贴边位置；离开目标窗口所在工作区时隐藏整组控件。右键编号可删除意见，旧编辑面板仍支持撤销和手动改写。

本地记录位于 `~/Library/Application Support/DuckIsland/Reviews/`，保留每张完整截图、编号标注图、区域坐标、文字及 JSON。预览缩放不影响保存分辨率。新录音按识别片段保存本地时间戳（HH:mm:ss），旧记录不补造时间。编辑后的意见与原始转写分别保留。语音不保存原始音频；复制可能随通用剪贴板同步到其他设备，Codex 的服务处理遵循用户的 Codex 设置。

Option + E 保存当前批阅并解除目标窗口绑定（不退出目标应用）。左右 Option 均可使用；快捷键通过系统全局注册，无需辅助功能权限。历史窗口顶部横向切换截图，下方左侧完整大图、右侧转写和可编辑意见；点击图中框选切换意见。

Option + Shift + Enter 全局打开启动框（即使只有一个可选窗口也保留列表）。每次仅附着一个窗口；切换前保存旧批阅，`Option + E` 保存并解除附着，不关闭目标应用。输入的“意图”会写入批阅复制、Notes、Claude、Codex 导出内容，不进入 AI Summary。

“恢复最近批阅”位于菜单栏，批阅球空白时右键菜单中也有该项。

目标窗口列表居中显示于主窗口所在屏幕，仅保留搜索框、窗口列表和退出项，支持搜索应用名与窗口标题。呼吸灯右下按钮切换 Text / Audio，以蓝色麦克风和紫色文字图标区分，默认 Audio：拖动框选自动录音；Text 模式拖动框选后插入文字意见（单击不创建），直接输入并自动保存，切换前会等待录音收尾。

窗口列表按实时搜索结果自动调整高度，超过上限时滚动。输入后默认高亮第一项，↑ / ↓ 切换高亮、Enter 确认；输入 e 优先匹配“退出批阅”，无匹配时 Enter 不执行操作。

框选左上角编号可拖动整个框选；右侧、底部和右下角可调整大小，范围限制在截图内。右上角 × 删除框选及对应意见。⌘Z 可撤销新增、移动、缩放、删除；每次拖拽只算一步，撤销几何调整保留最新意见及转写。

Audio 模式框选后自动录音；每个框选顶部中间的麦克风可开始录音，录音时变为红色停止按钮。呼吸灯按钮仍负责切换 Audio/Text；从 Text 切回 Audio 时，会继续录入当前选中的意见（若有）。

历史与完成合并为呼吸灯左下方的圆形历史入口：点击先收尾录音并保存，再打开独立历史页。Notes、复制、Codex 位于历史页底部“保存并关闭”旁，处理前保存最新编辑，处理后保留历史页。

选定目标窗口后自动截图进入批阅。Esc 保存并退出批阅模式、保留目标绑定；输入法组词期间 Esc 仍由输入法处理。呼吸灯下方改为 Live Transcript，创建或切换意见时追加高亮记录，语音和文字输入实时更新当前记录，旧记录保留切换时的内容。

批阅麦克风每次启动时跟随系统默认输入，使用独立 AVCaptureSession 采集。Live Transcript 显示实际设备名、输入电平和录音/识别错误；灵动岛实时显示录音、转写、读屏与批阅状态。

Live Transcript 右上提供输入设备选择器，默认跟随系统，可指定麦克风；录音中切换会先收尾再续录当前意见。Live Transcript 与历史页均提供 AI Summary / CleanUp，点击后使用已登录的 Codex 整理各框选编号的关键点及精简意见，保留原文；结果保存到本地批阅，转写更新后标记待刷新。AI 请求仅发送文字，不附截图，失败保留原始内容与已有结果。

GPT-Live：呼吸灯下方默认显示 Chat Messages，可切回 Transcript。设置中填写个人 OpenAI API Key 并存入系统钥匙串，也可从 ~/.config/env 的 OPENAI_API_KEY 导入；首次开始且钥匙串无凭据时自动尝试导入，不使用 OPENROUTER_API_KEY。使用 gpt-live-1 / Marin，用户点击开始后发送麦克风音频与当前批阅文字上下文，不上传截图。Chat 显示双方实时字幕并随批阅保存，结束对话停止采集和播放，等待服务端收尾；建议佩戴耳机减少回声。对话运行时暂停本地批阅录音，不能同时开始会议录音。需要 API 模型访问权限与可用余额，ChatGPT/Codex 订阅不作为此功能的凭据。

GPT-Live 设置支持可选 HTTP 代理（例如 http://127.0.0.1:7897），留空使用系统网络；代理地址不允许内嵌凭据。连接阶段临时 TLS/网络失败会自动重试一次，取消或结束后不会重连，证书校验保持系统默认。

对话与转写现合并为一条消息流：默默 · #N 显示该框选的口述记录，用户与默默的对话穿插显示。呼吸灯右下按钮切换发言/静默，默认静默；静默停止远程会话与播放，继续既有听写，只记录不回复。发言连接 GPT-Live，结合默默/Momo 唤醒词、明确提问及模型指令控制回复；意图门禁为启发式，真实效果需语音验收。文字框选与语音框选切换保留在呼吸灯右键菜单。
